    Server address

    play.yourserver.net

    1. Open Minecraft Java

      Launch the game on version 26.2 from any preferred launcher.

    2. Go to Multiplayer

      Pick Multiplayer on the title screen, then Add Server.

    3. Paste the address

      Name it anything and paste the server address from the box.

    4. Join and say hi

      Select the server, press Join Server and read the rules at spawn.
